# Rain on a tin roof, starlight still arriving

A short passage written to slow the reader down: an afternoon of rain on a tin roof in a town no map has ever named, tea-coloured light under the eaves, and stars that set out before anyone living was born and are still on their way here.

## Run

```sh
node main.ts
```

This writes the passage to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `out/entry.txt`), checks it is 1–280 characters, and reads it back to verify it matches exactly.
